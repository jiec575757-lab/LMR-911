# LMR 私人影像刊

一本关于自己的互动写真杂志。包含封面、目录、南京、河南、生活、生日、写真、后记、影像档案和封底，共 22 页，使用全部 35 张原始照片。

新增「Strawberry reverie / 草莓白日梦」写真章节（第 13–18 页），收录「朋友圈/写真」文件夹中的 9 张照片。版式延续照片里的草莓粉、碎花、浅绿与窗边柔光，穿插大幅肖像和叠放双照片。第 20 页影像档案以 6 列网格集中展示全部 35 张照片，点击均可放大和收藏。

在线阅读：<https://jiec575757-lab.github.io/LMR-911/>

杂志以居中的纸质书页呈现，周围留有阅读空间。桌面显示双页，手机显示单页，书页按屏幕尺寸等比例缩放。封面只展示一张完整照片；竖版照片不会被裁切。封底的大标题、寄语和返回按钮各自留有间距。

## 打开

双击 `index.html`，即可在浏览器阅读，无需安装或联网。`assets` 文件夹必须与网页一起保留。

开发预览也可以在这个文件夹运行 `python -m http.server 4173 --bind 127.0.0.1`，然后访问 http://127.0.0.1:4173 。

## 互动

- 桌面显示双页，手机显示单页。点击两侧箭头，或用方向键 / PageUp / PageDown 翻页；手机支持左右滑动。
- 上下工具栏默认分别隐藏。右上「工具」打开目录、收藏、音效与全屏等工具；右下「翻页」打开页码和进度。展开和收起都不会改变照片大小，Escape 可以收起两栏。
- 顶部目录可跳转到五个章节，底部短横线可跳转页面。Home 回到封面，End 跳到封底。
- 点击照片查看原图比例；照片查看器支持左右箭头、滑动、方向键和 Escape。
- 在照片查看器中点击爱心收藏，顶部爱心可查看收藏。收藏与阅读背景保存在当前浏览器。
- 支持深浅阅读背景、全屏和可选的翻页音效。默认静音，自动遵循系统减少动态效果设置。
- 后记页有一封可以拆开的信；影像档案可以浏览全部 35 张照片。第 9 页生活日记以新增的白色床品照片为主图，搭配另外三张日常照片；「此时情绪此时天 / 无事小神仙」文案继续保留。

## 文件

- `index.html`：网页结构与阅读工具。
- `styles.css`：响应式布局、杂志排版和 3D 翻页动画。
- `app.js`：照片文字、22 页编排及互动；翻页导航和页数随页面定义计算。
- `assets`：本地照片、缩略图和字体。照片经过等比例缩小与压缩，原始素材保持在上一级「朋友圈」文件夹。
- `asset-manifest.json`：原始照片与网页资源的对应关系。
- `tools/prepare_assets.py`：从原始素材新增网页照片和联系表，需要 Python 和 Pillow。默认保留已有压缩资源；传入 `--refresh` 可重新生成全部照片。支持 JPG、JPEG、PNG 和 WebP。

字体为 Bodoni Moda（SIL Open Font License），字体与图片均本地加载。封面照片保持原始方向与色彩。网页中的文字为写真杂志的创作性文案。

分享时请复制整个 `lmr-magazine` 文件夹，或把其中的网页文件与 `assets` 上传到你选择的静态网站服务。
